## 1. 내 성취도 기록실 (새 화면)

1. 허브 우상단 `🏅 내 기록실 2/10 클리어` 버튼 → 기록실 진입
2. 버튼 숫자 = 지금까지 딴 메달 수
3. 제목 `🏆 내 성취도 기록실`
4. 우상단 `이미지로 저장` → 기록증 PNG 다운로드
5. 좌하단 토글로 **카드 / 표** 배치 전환 (색은 배치가 정함, 따로 안 고름)
6. 무대 4개 순서대로 — 스타트 게이트 · 비기너 아케이드 · 마스터 아케이드 · 챔피언 홀
7. 맨 아래 `나의 진척` 판
8. **표 배치** — 한 무대가 표 하나. 열은 `타이틀 · 1단계 · 2단계 · (3단계) · 메달 · 액션`
9. 단계 열 수는 무대마다 다름 — 스타트 1 · 비기너 2 · 마스터/챔피언 3
10. 단계 칸 = 그 단계 최고 등급 (`S A B C D`, 이론관은 `수료`)
11. 미도전 단계는 `-` — 몇 단계짜리 방인지 같이 읽힘
12. 단계 칸 hover → 단계 이름 툴팁
13. 메달 칸 = 클리어 시 `🏅`
14. 액션 버튼 = 기록 있으면 `다시 도전 ▶`, 없으면 `플레이하기 ▶` → 해당 게임 진입
15. 행 hover → 그 줄만 밝아짐
16. **카드 배치** — 카드 하나가 방 하나. 왼쪽 아이콘 · 가운데 이름과 배지 · 오른쪽 메달
17. 단계 배지 = 번호 + 등급 (`① A` `② S`)
18. **카드 전체가 버튼** — 안에 별도 버튼 없음
19. hover → 손 커서 · 카드 떠오름 · 테두리 밝아짐
20. 2단 흐름, 900px 이하에서 1단
21. **나의 진척** — 금색 진행바 = 클리어 ÷ 10
22. `무대 10개 중 2개 클리어 · 3개 플레이` + 우측 퍼센트
23. 안내 한 줄 `🏅 메달은 모든 단계를 A등급 이상으로 통과해야 받아요` (다 모으면 사라짐)
24. **메달 진열장 10칸** — 딴 것만 원색, 나머지 흑백
25. 진열장 아이콘은 방마다 다름 — `🎓 💡 🎵 🌈 🔆 🎚️ 🔨 🪔 💣 👑`
26. 칸 hover → 방 이름 · 메달 이름
27. 하단 `👑 천국의 왕관까지 8개` → 다 모으면 `모두 모았어요!`
28. 열어 둔 채 게임 결과가 들어오면 자동 갱신

## 2. 이미지로 저장 — 성취도 기록증

29. 화면 캡처가 아니라 **A4 비율 흰 종이 문서**를 따로 만들어 PNG 로 저장
30. 파일명에 날짜 — `미니게임천국_성취도기록증_2026-08-18.png`
31. 상단에 `성취도 기록증` 제목 + 브랜드 줄
32. **`이름` 칸은 빈 밑줄** — 인쇄 후 손으로 기입
33. 머리말에 발급일 + `무대 10개 중 2개 클리어 · 3개 플레이`
34. 열 = `무대 · 미니게임 · 단계별 등급 · 메달`
35. 안 해 본 방 포함 10줄 전부
36. 단계별 등급은 번호와 함께 알로, 미도전은 `–` 알
37. 메달 칸은 딴 방만 금색 알 `✓`
38. 바닥글에 등급 기준 · 메달 규칙 · `천국의 왕관까지 N개`
39. 등급 색은 화면과 같은 계열 (S 보라 · A 로즈 · B 파랑 · C 주황 · D 회색 · 수료 초록)
40. 이모지 미사용 — 기기마다 그림이 달라지고 흑백 인쇄에서 뭉갬

## 3. 이론관 · 전시관

41. 이론 글자 크기 · 대비 상향 — 교실 뒤 원거리 기준
42. 이론 설명 이모지 → **선으로 그린 SVG 아이콘 36종**
43. 이론 문장 줄바꿈을 의미 단위로
44. 강조 키워드 색 = 옆 그림 색
45. 복도 **간판 클릭**으로 방 이동 · 입장 (기존: 키보드로 걸어가야 함)

## 4. 앱 전체

46. **뒤로가기 버튼 위치 통일** — 허브 · 챕터만 아래로 내려가 있던 것을 맞춤
47. 음소거 · 보드 연결 · 모드 전환 버튼 → **아이콘** (9개 화면)
48. **새로고침해도 보던 화면으로 복원** — 중간 화면이 스쳐 지나가지 않음
49. 화면 전환 · 애니메이션이 OS `동작 줄이기` 설정을 따름
50. 개발용 기능(건너뛰기 · 무대 잠금 해제)은 배포본에서 제외

## 5. 메달 규칙

51. 매 판 기록 — **통과 못 해도 남음**
52. 통과 못 해도 다음 단계로 진행 — 막으면 학습자가 포기함
53. 등급은 내려가지 않음 — 더 잘한 판만 반영
54. **방의 모든 단계 통과** 시 메달 + 축하 화면
55. 한 번에 다 통과할 필요 없음 — 오늘 1단계, 다음에 2단계도 인정
56. 단, 도장은 **마지막 단계를 마친 순간**에 찍힘
57. 기록은 이 브라우저에만 저장 — 다른 PC 에서는 이어지지 않음
