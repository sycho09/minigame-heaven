# Playino : 미니게임천국 — 제품 소개서 (v2 확정 — 실제 제작 BOM 반영)

> 센서를 **미니게임**으로 배우는 피지컬 코딩 키트
> *(v1의 서보·조이스틱·초음파는 BOM에서 제외되고 가변저항이 추가되어 v2로 갱신)*

## 1. 제품 소개
마스코트 **EDDIE**와 함께 센서 6종을 미니게임 7개로 익히고, **응용·심화**로 나만의 작품까지 완성하는 STEAM 피지컬 코딩 키트.

- **핵심 컨셉** — 센서 1개 = 전용 미니게임 1개. 이론관(원리) + 체험관(게임).
- **대상** — 초등 고학년 ~ 중등 (가정·방과후·학원·학교 교구)
- **학습 환경** — Chrome / Edge (PC·노트북·크롬북), USB 연결. 설치 불필요, 접속 링크/코드.
- **구조** — 메달 수집 → 진척 100% 달성 시 졸업.

## 2. 학습 구성 (3단계)
| 단계 | 성격 | 내용 |
|---|---|---|
| **1단계 개별학습** | 센서 원리·제어 | 센서별 미니게임 **7개** |
| **2단계 응용학습** | 감지→동작 (피지컬 컴퓨팅 핵심) | 입력+출력 조합 작품 **2개** |
| **3단계 심화학습** | 창작 (브랜드 클라이맥스) | 나만의 인터랙티브 쇼 **1개** (졸업 작품) |

## 3. 구성품 리스트
**공통** — Arduino Uno(호환) · Grove Base Shield · USB 케이블 · Grove 케이블 · 수납 박스 · 퀵스타트 가이드(QR)

**센서 6종 (출력 3 · 입력 3)**
| # | 센서 | 입/출력 | 대표 게임 |
|---|---|---|---|
| 1 | LED ×3 (빨강·노랑·초록) | 출력 | 반짝반짝 라이트쇼 |
| 2 | 부저 (Passive) | 출력 | 멜로디 연주단 |
| 3 | RGB LED | 출력 | 무지개 물감놀이 |
| 4 | 조도센서 (CDS) | 입력 | 손그림자 마술 |
| 5 | 가변저항 | 입력 | 볼륨 다이얼쇼 |
| 6 | 택트스위치 ×2 | 입력 | 두더지 잡기 · 청기백기 |

> Grove 기반(무납땜·케이블식)으로 초·중등도 쉬운 세팅. 무선(BLE) 모듈은 **별매 액세서리**로 추후. 단가·모델·인증(KC)은 별도 확정.
> ※ 서보모터·조이스틱·초음파 거리센서는 BOM에서 **제외**(해당 게임도 삭제) — 대신 가변저항을 추가.

## 4. 커리큘럼

### ① 개별학습 — 센서별 미니게임 7
| 센서 | 게임 | 장르 / 학습 |
|---|---|---|
| LED | 반짝반짝 라이트쇼 | 리듬 · 디지털 출력/타이밍 |
| 부저 | 멜로디 연주단 | 리듬 · tone/주파수 |
| RGB | 무지개 물감놀이 | 색 맞추기 · PWM 색 혼합 |
| 조도(CDS) | 손그림자 마술 | 반응+생존 · 아날로그 입력(빛) |
| 가변저항 | 볼륨 다이얼쇼 | 정밀 조작 · 아날로그 입력 |
| 택트스위치 ×2 | 두더지 잡기 | 연타/반응 · 디지털 입력 |
| 택트스위치 ×2 | 청기백기 | 명령 따라 누르기 · 디지털 입력 |

### ② 응용학습 — 감지→동작 조합 2
| 작품 | 센서 조합 | 배우는 핵심 |
|---|---|---|
| 🪔 빛 마법 램프 | 조도센서 + RGB LED | 손 그림자로 빛 조절 → 목표 색 맞추기 (아날로그 입력→색 출력) |
| 💣 폭탄 해체반 | 가변저항 + LED ×3 | 다이얼로 주파수 맞춰 LED 끄며 해체 (정밀 조작 + 디지털 출력) |

### ③ 심화학습 — 졸업 작품 1
| 작품 | 센서 조합 | 내용 |
|---|---|---|
| 👑 나만의 인터랙티브 쇼 | 가변저항+RGB+부저+택트스위치×2 | 배운 부품을 모아 빛·소리 인터랙티브 쇼를 완성하는 졸업 작품 |
