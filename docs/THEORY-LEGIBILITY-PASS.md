# 이론관 시인성 패스

> **상태**: 코드 적용 · 기계 검증 · 육안 검증 · 커밋 완료 (`theory-legibility-pass` → main)
> **최종 갱신**: 2026-08-18

## 1. 문제

요구사항은 "빔프로젝터·원거리에서도 보이게". 실측 결과 원인은 이모지가 아니라 **타이포 스케일과 대비**.

| 위치 | 전 |
|---|---|
| 이론 본문 `.bx-theory p` | 16px |
| viz 라벨 | 11.5px |
| 탭 `.bx-step`·`.tv-tab` | 13 / 14px |
| 이론관 캡션 `.ba-flow` | 18px |
| 연주판 Hz | 10.5px |

- 모니터 60cm 의 16px = 프로젝터 3~4m 의 약 28~30px → 본문조차 하한 미달
- **대비 미달** — `#8a90a0` 3.2:1 · `#9aa0ac` 2.6:1 (WCAG AA 4.5:1 기준). 프로젝터는 검정이 뜨고 흰색이 날아가 더 나빠짐
- **버그 발견** — `04-games.css` `.la-p { color:#fff }` 가 흰 카드(`#fbfcfe`) 위에 올라가 `e⁻`/`h⁺` 가 안 보였음

## 2. 무엇을 했나

### 원칙 — 역할별 2티어

- **원거리** (제목·캡션·흐름도 라벨·탭) — 적극 상향
- **책상** (핀 안내·상태·수치) — 가독 하한 14~15px 까지만

`🔌 초록 LED → D2` 는 보드 꽂으며 읽는 텍스트. 같이 키우면 화면만 답답해짐.

### 변경 파일

```
신규  src/app/icons.js                    인라인 SVG 아이콘 36종
신규  src/styles/parts/06-legibility.css  시인성 오버라이드 전부 (196줄)
수정  src/styles/main.css                 @import 한 줄 (맨 끝)
수정  src/scenes/basics.js                스타트 게이트 이론관

```

**기존 CSS 01~05 는 한 줄도 안 건드림.** `main.css` 규약(= @import 순서가 캐스케이드 순서, 덮으려면 뒤쪽 파트에 추가)을 그대로 따름.

### 아이콘 — 왜 SVG 인가

1. 이모지는 OS/브라우저마다 다른 글립 → Windows 에서 만든 화면이 크롬북·맥에서 다른 그림
2. 디테일이 많아 원거리에서 뭉갬. 시인성의 무기는 굵은 스트로크 + 단순 실루엣
3. `currentColor` 라 탭 활성/비활성이 CSS 만으로 따라옴

**색면 원판(`iconOrb`)** 은 36종 전부가 아니라 **흐름도 6곳만**(읽기·생각·동작 / 입력·보드·출력). 원거리에서는 글립보다 색면이 먼저 읽히기 때문.

### 되돌리기

| 무엇 | 방법 |
|---|---|
| 폰트·대비·크기 전부 | `main.css` 의 `06-legibility.css` import 한 줄 주석 |
| 아이콘만 | `icons.js` 의 `USE_SVG = true` → `false` |

`FALLBACK` 36종이 `PATHS` 36종과 1:1 이라 이모지로 완전 복귀 (A/B 비교용으로 유지).

### 검증에서 찾아낸 결함 6건 — 고침

이번 패스가 **새로 넣은 색**에서 기준 미달 (비텍스트 3:1 / 본문 4.5:1).

| 대상 | 전 → 후 |
|---|---|
| `.ic-think` 칩 | `#e07b20` 2.6:1 → `#a8560c` 4.5:1 |
| `.ic-act` 전구 | `#cf9500` 2.4:1 → `#8a6100` 5.0:1 |
| 슬라이드 ③ 입력 라벨 | `#3aa0e0` 2.6:1 → `#1f6aad` 5.0:1 |
| 슬라이드 ③ 출력 라벨 | `#e85a8a` 3.0:1 → `#c22f66` 4.8:1 |
| 이론 제목 아이콘 | `#ff7a3c` 2.6:1 → `#e35c10` 3.6:1 |
| `h⁺` 원판 흰 글씨 | 2.5:1 → 4.0~5.3:1 |

- 마지막 건 원인 — `radial-gradient(circle at 36% 32%, 밝은색, 어두운색)` 에서 원 중앙이 그라디언트의 28% 지점이라 **글자 자리가 밝은 쪽**. 바탕을 `linear-gradient` 로 깔고 광택을 별도 레이어로 분리해 해결
- 재검증은 **CSS 파일에서 색을 직접 파싱해 재계산**(의도값 아닌 실제값 기준). 19개 항목 전부 통과

기계로는 "규칙이 적용됨"까지만 증명됨. 크기·배치는 눈으로만 판정 가능.

- ✅ 마스터 아케이드(램프·폭탄) — 같은 오버레이라 자동 적용

**남은 결정 1건** — 전시관 사인(`📖 이론관`/`🎮 체험관`)을 이미지로 교체할지. 캔버스라 SVG 불가, `/brand/sign-theory.webp` · `sign-play.webp` 경로는 이미 코드에 있음.

**조정 포인트** — 캡션이 과하면 `.ba-flow { font-size: 28px }` · 원판이 크면 `.ic-orb { 84px }` · 세로 760px 이하 축소 규칙은 `06-legibility.css` 맨 아래.

## 6. 결정 기록 — 고치지 말 것

### 초기 청크 증가는 의도한 비용

크롬 아이콘 배선으로 초기 화면 5개가 `icons.js` 를 import. 그 화면들이 쓰는 건 2종인데 36종 전부가 실림.

> **2026-08-18** — 초기 청크는 현재 **89.71 kB**. 이 절의 `icons.js` 몫이 아니라
> 그 뒤에 붙은 기록실(`records.js` 정적 import)이 늘린 것. 아래 판단은 `icons.js` 에 한해 유효.

- **회귀가 아님** — 배경 이미지 한 장이 100~158 kB, `public` 전체가 3.7 MB. 증가분은 체감 차이가 아님
- **`icons-core.js` 로 쪼개면 안 되는 이유** — "초기 화면은 core, 지연 화면은 full" 규칙은 조용히 깨짐. 누가 `login.js` 에 새 아이콘을 쓰면 빈 화면이 나오는데 **에러도 없고 빌드도 통과**. 아이콘은 계속 늘어날 자리라 반드시 밟는 함정
- 정말 줄여야 하면 모듈 분리가 아니라 **아이콘별 named export(tree-shaking)**. 대신 호출부 약 186곳 수정 필요
- 레버가 더 큰 곳 — ① 기록실 지연 로딩 ② CSS 142.9 kB ③ 이미지 3.7 MB

### 라이선스 고지는 txt 가 지킨다

`icons.js` 의 `/*!` 고지는 **빌드에서 지워진다**(번들 grep 0건 — 2026-08-18 확인).
ISC·MIT 조건을 실제로 지키는 것은 배포물에 그대로 실리는 `public/THIRD-PARTY-LICENSES.txt` 다.
소스의 `/*!` 는 파일을 여는 사람을 위한 표시로만 남긴다.

### 아이콘 도형 출처가 섞인 것도 의도

표준 30여 종은 Lucide(ISC), 제품 고유 6종(`robot`·`board`·`brain`·`press`·`motor`·`digital`)만 직접 그림.

기준은 출처가 아니라 **제도 규격** — 양쪽 다 viewBox 24 · `fill:none` · round cap/join, 스트로크 2.3 통일. 구워 보면 구분되지 않음.

6종을 직접 유지한 근거는 `icons.js` 헤더에 있음. 요약 — Lucide 대응물이 **우리 크기(21~29px)·우리 의미에서** 더 나빴음 (`mouse-pointer-click` 은 손가락이 아니고, `square-activity` 는 사각파가 아님). 전부 래스터화해 확인.
