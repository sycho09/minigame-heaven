# 🎡 Eduino AI : 미니게임천국 — 기획 백업

> 기준: **모두 Claude(에디 기획) 기준**으로 진행. 이 문서는 합의된 방향의 단일 백업본.

## 0. 제품 정체성
- Vite 바닐라 JS · WebSerial로 실제 아두이노(이지 커넥트 키트) 제어하는 **브라우저 교육 게임**.
- 6자리 접속코드로 입장(데모는 아무 코드). 모든 상태 localStorage.
- 마스코트 **EDDIE**(노란 TV-머리 로봇)가 무대를 돌며 미니게임 클리어 → 메달 수집 → 학습 100%.

## 1. 핵심 원칙 (항상 명심)
1. **게임 ↔ 실물 상호작용이 최우선** — 화면 게임이 실제 센서/LED와 연결돼 움직여야 한다.
2. **약간의 블록코딩 허용** — 필요하면 블록코딩 수준의 가벼운 코딩 체험을 넣어도 된다.
3. **게임 시작 전 센서 설명** — 사용 센서가 뭔지/원리/활용을 먼저 알려준다.
4. **그림체 고정 · 게임은 다양**: 1930s rubber-hose, muted 배경 + vibrant 전경. 부스마다 다른 메커닉.
5. **아트 스타일만 통일, 장면/구도/게임은 매번 다르게.**

## 2. 박물관형 센서 전시관 (방 구조)
센서 부스에 입장하면 **하나의 전시관**:
- 📖 **이론관**: 센서 정의·원리·활용 + 블록코딩 미리보기 (박물관처럼 학습)
- 🔌 **결선관**: 회로/포트 안내 + 보드 연결 진단(WebSerial)
- 🎮 **체험관**: 미니게임(들). 클리어 → 메달.
→ 교육(이론) + 준비(결선) + 게임(체험)을 한 방에. (현재 LED부터 적용)

## 3. 무대(스테이지) = 커리큘럼 4단계
1. 🎪 **시작의 천막** — 피지컬 코딩 기초(이론+퀴즈+분류). 센서 없음.
2. 🏛️ **기초의 전당** — 센서 개별(1종).
3. 🎭 **응용 대극장** — 2종 조합 응용.
4. 🕌 **마법의 돔** — 3종 이상 심화/종합 → 졸업 👑.

## 4. 미니게임천국 선정 부품 (6종) — 빛·소리·조작·반응 위주
> 구성품 BOM 확정: LED ×3 · 수동 부저 · RGB LED · 조도센서 · 가변저항 · 택트스위치 ×2.
> 모두 **3핀 커넥터** 통일, 연결 케이블 **3핀 ×5**(동시 최대 5개). 서보·초음파·조이스틱·7세그·매트릭스·기울기·소리감지는 제외.

### 기초의 전당 (센서 개별 · 7종)
| 센서 | 게임 | 메커닉 |
|---|---|---|
| 🟢🟠🔴 LED 3종 | 반짝반짝 라이트쇼 | 타이밍 + 멜로디 연주(작은별) |
| 🔊 수동 부저 | 멜로디 연주단 | 음정 연주 |
| 🌈 RGB LED | 무지개 물감놀이 | 색 맞추기(슬라이더) |
| 🔆 조도 센서 | 손그림자 마술 | 빛 가리기 반응 |
| 🎚️ 가변저항 | 볼륨 다이얼쇼 | 정밀 조작 |
| 🔘 택트스위치 ×2 | 두더지 잡기 | 버튼 2개 반응/연타 |
| 🚩 택트스위치 ×2 | 청기백기 | 명령 따라 버튼 누르기 |

### 응용 대극장 (2종 조합 · 2종)
| 조합 | 게임 | 메커닉 |
|---|---|---|
| 🔆 조도 + 🌈 RGB | 🪔 빛 마법 램프 | 손 그림자로 빛 조절 → 목표 색 맞추기 |
| 🎚️ 가변저항 + 🟢🟠🔴 LED | 💣 폭탄 해체반 | 다이얼로 주파수 맞춰 LED 끄며 해체 |

### 마법의 돔 (종합)
- 가변저항 + RGB + 부저 + 택트 ×2 = "나만의 인터랙티브 쇼"(빛·소리 라이브) → 졸업 👑.

## 5. 다른 세계로 보류(추가 구매/스토리 확장)
| 미래 세계 | 센서 |
|---|---|
| 🚒 안전 도시 | 불꽃·MQ-2 가스·알코올·수증기 |
| 🌱 스마트팜 | 토양습도·수분·DHT11·물 |
| 🏠 스마트홈 | RTC·LCD·OLED·릴레이·리모컨 |
| 🕵️ 비밀요원/보안 | PIR·적외선장애물·레이저·리드/홀자석·노크·진동·충돌 |
→ **같은 키트로 5개 세계** = 1회 구매로 반복 사용 + 업셀.

## 6. 진행 순서(작업)
1. (완료) 광장/무대/기초/LED 라이트쇼(타이밍+연주) + 결선 진단 + 메달/현황.
2. LED 방을 **전시관(이론관+체험관)** 으로 구조화 ← 템플릿.
3. 기초 이론 스토리 강화 + 클리어 후 개념 카드.
4. 부저(멜로디 연주)부터 기초의 전당 게임 순차 제작.
