# EDDIE 리그 빠른 제작 (2D 슬라이스 — 3D 불필요)

> 목표: 기존 에디 그림 **1장을 5조각으로 잘라** 모든 페이지의 가이드 에디를
> *살아 움직이는 퍼펫*으로 만든다. 3D 모델링 없이 30분~1시간.
> 리그는 `src/app/eddieRig.js` + CSS 변형(회전)으로 동작하므로 **2D 레이어 5장**이면 끝.

---

## 0. 준비물
- 무료 브라우저 편집기 **Photopea**(https://www.photopea.com) — 포토샵과 동일 UX, 설치 불필요
- 슬라이스 원본: **정면 전신 에디 1장**
  - 기존 `public/brand/eddie/eddie-hero.webp` 를 써도 되고,
  - 더 깔끔하게 하려면 *정면·차렷·팔이 몸통과 안 겹치는* 에디를 한 장 준비(생성형으로
    컨셉만 뽑아도 OK — 어차피 이 1장이 리그의 원본이 된다)

---

## 1. 캔버스 세팅 (한 번만)
1. Photopea 에서 원본 열기
2. 이미지 크기를 **1024 × 1024 정사각**, 배경 **투명**으로 (Image → Canvas Size)
3. 에디를 **정중앙, 발끝이 하단 가까이(약 92%)** 오도록 배치
4. 아래 "세로 위치 가이드"에 대략 맞으면 애니메이션 축과 잘 맞는다:

```
  0% ┬ (상단)
  ~8% │  ● 안테나 끝
 ~22% │  ◉ 안테나 밑동 / 머리 위        ← 안테나 회전축
 ~22% ┤
      │  ▢ 머리(TV+눈)
 ~46% │  ◗ 목·머리/몸통 연결            ← 머리 회전축
 ~44% │  ↤ 어깨(좌 60% / 우 40%)        ← 양팔 회전축
      │  ▮ 몸통
 ~65% │
      │  ▙ 다리
 ~92% ┴  발끝 (하단)
```

> 그림이 이 비율과 좀 달라도 됨. 핵심은 **머리는 위, 어깨는 중앙, 안테나는 꼭대기**.

---

## 2. 5조각으로 분리 (핵심)
원본 레이어를 **5번 복제**하고, 각 복제본에서 *필요한 부위만 남기고 지운다*.
**절대 위치를 옮기지 말 것** — 5장 모두 같은 1024 캔버스의 *제자리*에 있어야 겹쳐서 맞는다.

| 내보낼 파일 | 남길 것 | 지울 것 |
|---|---|---|
| `body.png`    | 몸통 + 다리 | 머리, 양팔, 안테나 |
| `head.png`    | 머리(TV+눈) | 그 외 전부 |
| `arm-l.png`   | **왼쪽**(화면 기준) 팔 | 그 외 전부 |
| `arm-r.png`   | **오른쪽** 팔 | 그 외 전부 |
| `antenna.png` | 안테나 | 그 외 전부 |

### 잘릴 때 틈 안 생기게 (중요)
- 관절(목·어깨·안테나 밑동)은 **딱 자르지 말고 약간 겹치게** 남겨라.
  예) `body` 에 어깨/목 살을 조금 포함, `head` 에 목 아래를 조금 포함.
  회전할 때 겹친 부분이 빈틈을 가려준다.
- 팔은 회전축(어깨)에서 시작하므로 **어깨 위쪽 살을 팔 레이어에 조금** 포함.

---

## 3. 내보내기
각 레이어만 보이게 한 뒤 **File → Export as → PNG**(투명) 로 5개 저장:
`body.png` `head.png` `arm-l.png` `arm-r.png` `antenna.png`

→ 저장 위치: **`public/brand/eddie/rig/`** (폴더 새로 만들기)

---

## 4. 최적화 + 배포 (명령 3줄)
```
npm run assets      # rig/*.png → 1024 WebP 로 변환(원본 png 자동 교체)
npm run build       # 빌드 확인
git add public/brand && git commit -m "EDDIE 리그 5부위 추가" && git push
```
배포 Ready 후 브라우저에서 **Ctrl+Shift+R** → 가이드 에디가 머리 갸웃·팔 흔들·안테나
떨림으로 살아난다. (5장 다 있으면 자동으로 `rigged` 모드 ON)

---

## 5. 미세조정 (선택)
움직임 폭/속도는 `src/styles/main.css` 의 키프레임에서:
```
@keyframes er-head    { 50%{ transform: rotate(2.5deg) } }   /* 머리 갸웃 폭 */
@keyframes er-arm-r   { 50%{ transform: rotate(10deg) } }    /* 오른팔 스윙 폭 */
@keyframes er-arm-l   { 50%{ transform: rotate(-7deg) } }    /* 왼팔 스윙 폭 */
@keyframes er-antenna { 50%{ transform: rotate(5deg) } }     /* 안테나 떨림 폭 */
```
회전축이 어긋나 보이면 `.er-head / .er-arm-* / .er-antenna` 의 `transform-origin`
(`50% 46%` 등) 을 조절. 현재 값은 위 "세로 위치 가이드" 기준으로 맞춰둠.
