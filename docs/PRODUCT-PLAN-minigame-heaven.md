# Eduino AI : 미니게임천국 — 신제품 개발 기획안 (v1 / 확정용 초안)

> 작성 목적: 하드웨어 키트 + 호환 게임 소프트웨어를 **하나의 패키지 신제품**으로
> 출시하기 위한 기획·구성품 확정. 본 문서로 1차 스펙을 합의한 뒤 BOM·가격·인증을
> 후속 확정한다.

| 항목 | 내용 |

| 제품명 | **Eduino AI : 미니게임천국** (키트 + 게임 번들) |

## 2. 타겟 사용 환경 & 연결 방식 (확정)

| 기기 | 연결 방식 | 지원 |
|---|---|---|
| **PC / 노트북 / 크롬북** | USB 케이블 (WebSerial) | ✅ 기본 |
| **안드로이드 태블릿** | **BLE 무선** (HM-10 / Grove BLE, Web Bluetooth) | ✅ |
| 아이패드(iOS) | (Safari 미지원) | ❌ 제외 |

- 브라우저: **Chrome / Edge** (데스크톱·안드로이드). 설치 불필요.
- 웹앱: Vercel 호스팅, **접속 링크/코드**로 입장. 로컬 설치 없음.
- 연결 추상화: 앱 내부 `board` 계층이 USB(WebSerial)·BLE를 동일 인터페이스로 처리 → 기기에 맞게 자동/선택.

## 3. 제품 구성 (2요소 번들)

### A. 하드웨어 키트
- Arduino Uno 호환 보드 **베이스**
- **Grove 시스템** 기반(납땜·브레드보드 없이 케이블 꽂기만) → 초·중등 세팅 난이도 최소화
- 무선 학습용 **BLE 모듈** 포함

### B. 소프트웨어 (게임 + 학습)
- 웹 기반 **미니게임천국**: 마스코트 EDDIE 가이드, 센서별 **이론관 + 체험관(미니게임)**
- 메달 수집 → 진척 100% 졸업 구조
- 접속 코드 1개 = 1 학습자(또는 좌석) 라이선스 (정책 후속 확정)

## 4. 커리큘럼 ↔ 센서 ↔ 게임 매핑

> 핵심: **구성품(센서) 하나하나가 전용 게임/이론관과 1:1**. 키트 구성은 소프트웨어와 일치시킨다.

### 🎪 CH1 시작의 천막 — 기초
| 학습 | 내용 | SW 상태 |
|---|---|---|
| 보드 연결 / 피지컬 코딩 기초 | 환경설정·개념·분류 미션 | ✅ 구현 |

### 🏛️ CH2 기초의 전당 — 7종 (★ 1차 제품 핵심, BOM 부품과 1:1)
| 센서 | 게임 | 학습 개념 | SW 상태 |
|---|---|---|---|
| LED ×3 | 반짝반짝 라이트쇼(리듬) | 디지털 출력·타이밍 | ✅ 구현 |
| 부저(Passive) | 멜로디 연주단(리듬) | tone·주파수 | ✅ 구현 |
| RGB LED | 무지개 물감놀이(색 맞추기) | PWM 색 혼합 | ✅ 구현 |
| 조도센서(CDS) | 손그림자 마술(반응+비행) | 아날로그 입력(빛) | ✅ 구현 |
| 가변저항 | 볼륨 다이얼쇼 | 아날로그 입력 | ⏳ 예정 |
| 택트스위치 ×2 | 두더지 잡기(버튼 2개) | 디지털 입력 | ⏳ 예정 |
| 택트스위치 ×2 | 청기백기(명령 따라 누르기) | 디지털 입력 | ⏳ 예정 |

> ※ 서보(SG-90)·초음파·조이스틱·7세그는 BOM에서 **제외** → 해당 게임(행운의 룰렛·무궁화·우주조종·번개점수판) 삭제.

### 🎭 CH3 응용 대극장 — 2종 조합 2종 (BOM 부품만으로 신설)
| 조합 | 게임 | 학습 개념 | SW 상태 |
|---|---|---|---|
| 조도센서 + RGB | 🪔 빛 마법 램프 (손 그림자로 색 맞추기) | 아날로그 입력→색 출력 | ⏳ 예정 |
| 가변저항 + LED ×3 | 💣 폭탄 해체반 (다이얼로 주파수 맞춰 해체) | 정밀 조작 + 디지털 출력 | ⏳ 예정 |

### 🕌 CH4 마법의 돔 — 종합
🏆 나만의 인터랙티브 쇼: 가변저항 + RGB + 부저 + 택트 ×2 종합 → 빛·소리 라이브쇼 → 졸업 👑

## 5. 구성품 리스트 (BOM 초안 — Grove 기준)

### ▣ 기본 키트 (1차 제품 = CH2 7종 + CH3 응용 2종 + CH4 종합 대응)
| # | 구성품 | 규격/모델(예) | 수량 | 용도(게임) |
|---|---|---|---|---|
| 1 | 메인 보드 | Arduino Uno(호환) | 1 | 전 게임 공통 |
| 2 | Grove 베이스 실드 | Base Shield v2 | 1 | Grove 무납땜 연결 |
| 3 | USB 케이블 | USB-B, 1m | 1 | PC/크롬북 연결·전원 |
| 4 | **BLE 모듈** | **Grove BLE (HM-10/HM-11)** | 1 | **안드로이드 태블릿 무선 연결** |
| 5 | LED ×3 | 빨강·노랑·초록 각 1개 | 3 | 라이트쇼·폭탄 해체반·인터랙티브 쇼 |
| 6 | 부저 | Grove Buzzer(Passive) | 1 | 멜로디 연주단·인터랙티브 쇼 |
| 7 | RGB LED | Grove RGB LED | 1 | 무지개 물감놀이·빛 마법 램프·인터랙티브 쇼 |
| 8 | 조도센서 | Grove Light Sensor(CDS) | 1 | 손그림자 마술·빛 마법 램프 |
| 9 | 가변저항 | Grove Rotary Angle Sensor | 1 | 볼륨 다이얼쇼·폭탄 해체반·인터랙티브 쇼 |
| 10 | 택트스위치 ×2 | Grove Button (노랑·빨강) | 2 | 두더지 잡기·청기백기·인터랙티브 쇼 |
| 11 | 연결 케이블(3핀) | 3핀 커넥터 케이블 | **5** | 동시 최대 5개 연결(최종 인터랙티브 쇼 기준) |
| 12 | 수납/패키지 | 박스 + 인서트 트레이(멀티박스) | 1 | 보관·휴대 |
| 13 | 퀵스타트 가이드 | 인쇄물 + QR(웹 접속) | 1 | 첫 연결 안내 |

> ※ 모든 센서·모듈은 **3핀 커넥터** 통일 → 케이블 1종(3핀)만 사용. 4핀·5핀 불필요.
> ※ 케이블 최소 **5개** 근거: 한 게임 안에서 동시에 꽂히는 최대 모듈 수 = 최종 인터랙티브 쇼(가변저항+RGB+부저+택트×2 = 5).
> ※ 서보·초음파·조이스틱·7세그 및 확장팩(매트릭스·사운드·기울기 등)은 이번 구성에서 제외.

> ※ 모델명은 Grove 호환 기준 예시. 단가·수급 따라 호환 모듈로 대체 가능.
> ※ **부저는 반드시 Passive(피에조)** — tone() 멜로디 위해.
> ※ BLE는 **HM-10 계열(BLE)** 만 사용(HC-06/05=클래식BT는 브라우저 연결 불가).

## 7. 안전 · 인증 (초·중등 교구 = 필수 검토)

- **KC 인증**(전기용품·어린이제품) — 국내 교구 판매 시 사실상 필수. 보드/모듈 KC 보유 여부 확인.
- 어린이제품 안전 — 모서리·소부품(질식) 주의, 연령 표기.
- 배터리(BLE 무선 시 전원) — 전원 방식 확정(USB 보조배터리 vs 전용).
- → **인증·전원 방식은 사업/품질팀과 별도 트랙으로 조기 착수** 권고.
